# AERONEX Flight Controller

This folder contains the flight controller hardware and firmware documentation for the AERONEX AI-powered search and rescue drone.

## Flight Controller

- Pixhawk 2.4.8
- ArduPilot firmware
- Mission Planner
- GPS and telemetry support

## Purpose

The flight controller is responsible for stabilization, navigation, autonomous flight, GPS-based positioning, and communication with the ground control station.
