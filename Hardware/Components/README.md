# AERONEX Components

This folder contains the hardware component specifications and datasheets used in the AERONEX search and rescue quadcopter.

## Main Components

- Pixhawk 2.4.8 Flight Controller
- 4 × 920KV BLDC Motors
- 4 × AIR GEAR 450 ESCs
- 4 × T1045 Propellers
- Custom Li-Ion Battery
- Power Distribution / Power Module
- NEO-M10 GPS
- Compass
- 3DR 433MHz Telemetry
- Flysky Radio Transmitter and Receiver
