# NIRMAAN_AERONEX-26

## AI-Powered Search and Rescue Operation Drone

An autonomous search-and-rescue drone designed to assist in locating and identifying people during emergency situations using aerial mobility, autonomous navigation, and AI-powered human detection.

## 🚁 Project Overview

AERONEX is an AI-enabled aerial search and rescue platform designed to support rescue teams by providing rapid aerial surveillance over areas that are difficult or unsafe for humans to access.

The system integrates:

- Autonomous flight and waypoint navigation
- AI-based human detection
- GPS-based positioning
- Real-time telemetry
- Aerial surveillance
- Emergency search and rescue support

## 🎯 Objectives

- Reduce the time required to search large or difficult terrains.
- Assist rescue teams in locating people from the air.
- Provide real-time aerial situational awareness.
- Enable autonomous navigation using GPS and a flight controller.
- Integrate AI-based human detection for identifying potential survivors.

## 🧠 Technology Stack

- Pixhawk 2.4.8 Flight Controller
- GPS & Compass
- OnePlus 6T for AI processing and camera input
- 920KV T Gear Motors
- AIR GEAR 450 ESCs
- T1045 Propellers
- 3DR 433 MHz Telemetry
- FlySky fs-i6 Radio Transmitter and Receiver
- Custom Li-ion Battery
- PCB-based power distribution
- Customised Automated Charging Station
